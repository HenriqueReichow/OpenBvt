# Display — from the u16 image to colours

How opensonar shows the u16 image (`docs/IMAGING.md`) on screen (`src/opensonar/display.py`).

## 1. Pipeline
```
ping ──image.xy / image.rtheta──▶ u16 image ──ColorMapper──▶ RGBA image ──GUI──▶ screen
                                  3×3 mean       thresholds, gamma, colormap, auto
```
- The display is a **pure function of the u16 image**: one 65536-entry lookup table (LUT) from u16 to
  colour. No logarithm and no extra filter.
- Display settings never change the recorded data.
- The XY image is cropped to the ping range before drawing (`opensonar.viewer.crop_to_range`).
- Smoothing on/off switches the 3×3 mean of the image generator.

## 2. Colour mapping
State: a colormap of N colours, a **bottom threshold** `b`, a **top threshold** `t` (u16 units,
`b < t ≤ 65535`), a **gamma** `γ` and an **auto** flag.

| `v` | colour |
|---|---|
| 0 | transparent (no data, outside the fan) |
| 1 … `b`−1 | first colour |
| `b` … `t` | colour number `round(((v − b)/(t − b))^γ · (N − 1))` |
| above `t` | last colour |

- `γ < 1` brightens weak echoes; the default is **γ = 0.5** (a square root).
- If `b ≥ t`, the interval gets the middle colour.
- The LUT is rebuilt only when `b`, `t` or `γ` change.

### 2.1 Auto intensity (on by default)
Before each image:
1. Histogram of the **non-zero** pixels in 4096 bins (`v >> 4`).
2. The new `b` is the 0.01 % point of the histogram and the new `t` the 99.99 % point, times 16.
3. The first image uses them directly; after that each threshold moves **1/5 of the way** to the new
   value per image, so the brightness does not flicker.
4. Limits: `t ≥ 1000` and `b ≥ 1`.

With auto on, γ goes back to 0.5; the manual values return when auto is turned off.

### 2.2 Manual controls
| Control | Maps to | Range / default |
|---|---|---|
| Sensitivity | `b` | 1 … 999; 20 |
| Intensity | `t = 1000 + 65535 − intensity` (more intensity ⇒ brighter) | 1000 … 65535; 10000 |
| Gamma | `γ` | 0.5 |

## 3. Colormaps
opensonar ships its own maps, generated by formula: **Copper** (default), **Grayscale**, **Jet** and
**Viridis**. It also reads `.cmap` files the user already has: no header, N colours × 3 bytes in the
order **blue, green, red** (usually 4096 colours, 12288 bytes), entry 0 for the weakest echo.
